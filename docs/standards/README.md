## Precedence

When instructions conflict, use the following order:

1. PlatformTrust Constitution.
2. Approved Architecture Decision Records.
3. Security requirements.
4. Engineering Handbook.
5. Engineering standards.
6. Epic and issue specifications.
7. Implementation preferences.

The conflict must be surfaced rather than silently resolved by an
implementation agent.

## Enforcement

Standards should be enforced through:

- Automated formatting.
- Static analysis.
- Type checking.
- Unit and integration tests.
- Security scanning.
- Pull request checks.
- Code review.
- Deployment gates.

A standard without appropriate enforcement is considered incomplete.
