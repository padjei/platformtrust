# PlatformTrust Epics

This directory contains specifications for major PlatformTrust capabilities.

An epic represents a meaningful product outcome that normally requires
multiple implementation issues.

## Naming Convention

```text
PT-EPIC-001-enterprise-identity.md
PT-EPIC-002-tenant-management.md
PT-EPIC-003-audit-foundation.md
