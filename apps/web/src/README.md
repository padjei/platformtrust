# src

Holds the Next.js application (App Router).

Layout:

- `app/` — routes, layouts, and pages (App Router).
- `components/` — reusable React components (many wrapping shared `packages/ui`).
- `hooks/` — custom React hooks (data fetching via TanStack Query, forms, etc.).
- `lib/` — client utilities: API client, Zod schemas, formatting, auth helpers.
